Sound effect credits
====================

Every sound here is CC0 (public domain dedication) or public domain, so none
of them legally require credit. Credit is still given below, since the authors
ask for it and it's good manners. Keep this file in step when you swap a sound.

Format: game file  <-  source file  (changes made)
